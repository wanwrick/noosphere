## Key Formulas

**Value Creation**:
$$\text{Value} = B - C = (\text{Consumer Benefit} - \text{Price}) + (\text{Price} - \text{Cost})$$

**Break-even for M&A**: Does deal create/capture more value **net of acquisition price**?

**Diversion Ratio**: If Firm X raises price 5%, what % of lost demand goes to Firm Y? → High ratio = merger profitable for pricing power

## Five Forces Cheat Sheet

| Force | Key Question | Most Important Factors |
|-------|-------------|----------------------|
| **Entry Threat** | Who could AND wants to enter? | MES, switching costs, network effects, resource access, retaliation |
| **Internal Rivalry** | How intense is competition? | Overcapacity, differentiation, growth rate, order size/frequency |
| **Buyer Power** | Can buyers squeeze you? | Concentration, switching costs, information, VI threat |
| **Supplier Power** | Can suppliers squeeze you? | Concentration, substitute inputs, VI credibility |
| **Substitutes** | What else solves the customer's problem? | Price-performance ratio, switching costs |
| **Complementors (6th)** | Who adds value to your ecosystem? | Alignment of incentives, value capture dynamics |

**Remedies**: Differentiate → Merge/Partner → Control resources → Get there first → Change channels → Vertically integrate

## VRIN Framework

```
Resource Assessment Matrix:

                    Rare?
               YES         NO
         ┌───────────┬───────────┐
    YES  │ CHECK:    │ Competitive│
Valuable?│ Inimitable│ Parity    │
         │ + Non-Sub?│           │
         ├───────────┼───────────┤
    NO   │ Unused    │ No        │
         │ Potential │ Advantage │
         └───────────┴───────────┘

If V+R+I+N → Sustained Competitive Advantage
If V+R but imitable → Temporary Advantage
If V only → Competitive Parity
```

**Three uses**: (1) Assess your resources, (2) Acquire/protect VRIN resources, (3) Think dynamically — VRIN characteristics change

**Resources are BROAD**: physical assets, expertise, IP, culture, data, relationships, brand, distribution

## Strategic Tradeoffs — Cost-Quality Frontier

```
Quality/
Differentiation
    ▲
    │    ★ Hermès
    │   ★ Gucci (1990s position)
    │  ╱ ← Frontier
    │ ╱
    │╱   ★ Target
    │    ★ Walmart
    └──────────────────► Low Cost

Key: Firms ON the frontier make a CHOICE.
Firms BELOW the frontier are inefficient.
Moving along the frontier = strategic tradeoff.
```

**Critical insight**: It's not just "offer a differentiated product" but "offer a product that will be **hard for a rival to respond to** given their strategic constraints."

## M&A Decision Framework

### Two Main Justifications

| Synergies ("Bigger Pie") | Market Power ("Bigger Slice") |
|:---|:---|
| Revenue: cross-sell, improve quality, new products | Reduce rivalry between merging firms |
| Cost: scale economies, eliminate redundancies, shared know-how | Increase power over buyers/suppliers |
| Innovation from combination | Deny rivals access to target |
| Better resource utilization | Reduce future R&D competition |

### Four Questions (ALWAYS Ask)

```
1. Value net of price?  ──► What specifically will be DIFFERENT?
2. Organic/partnership better? ──► Could a contract achieve the same?
3. Good fit?           ──► Culture, values, operational alignment?
4. Risks?              ──► Integration issues, dis-synergies, unintended consequences?
```

### Red Flags
- "For cash" → you always pay the value of cash
- "To diversify" → cheaper via financial instruments
- Related businesses ≠ unlocked synergies (AOL/Time Warner)
- Overvalued stock → incentive to acquire (agency problem)
- **Dis-synergies**: Ruining something good (Sears/Lands' End)
- **Warehouse test**: 30% full warehouses in same area = real synergy (consolidate)

## Vertical Integration — Four Types

| Type | Logic | Example |
|------|-------|---------|
| **1. Snatch margins** | Take profits from suppliers/buyers | Costco chicken (but more than just margins) |
| **2. Realize synergies** | Better coordination, information sharing | Zara: production + retail for fast fashion |
| **3. Limit opportunism** | Prevent hold-up, encourage alignment | Intel + Cloudera (asset specificity) |
| **4. Foreclose rivals** | Deny key inputs to competitors | Samsung glass → TV rivals (but Samsung keeps selling) |

**Key caution**: Always ask if contracts/partnerships could achieve the same at lower cost/risk

## Game Theory Essentials

### Opening Examples
- **Wargames (1983)**: Credibility/commitment problem (MAD). "The only winning move is not to play."
- **Patent Trolls**: Break tech détente because they can't be countersued (no manufacturing)
- **Evil Sister**: Orange splitting → win-win (juice vs. rind) becomes zero-sum when one sister exploits knowledge

### Game Setup
```
Three Inputs: (1) Players  (2) Actions  (3) Payoffs
Equilibrium: No player wants to change given others stay
Dominant Strategy: Best action regardless of others' choices
```

### Understanding Competitors
```
┌─────────────────┐
│ Resources/       │ → What CAN they do?
│ Capabilities     │
├─────────────────┤
│ Assumptions     │ → What do they BELIEVE?
├─────────────────┤
│ Motivation      │ → What do they WANT?
└─────────────────┘
⚠️ Avoid Strategic Narcissism (McMaster):
   Don't assume others see the game as you do
```

### Strategic Postures

| Evil Orc 👹 | Fat Cat 😸 |
|:---|:---|
| Aggressive, grab all opportunities | Conciliatory, give rivals enough |
| Respond fiercely to threats | Seek mutual advantage |
| Microsoft bundling, Intel rationing | Coke & Pepsi coexistence |

### Credibility Test
```
For a signal to work:
1. Opponent must WANT to respond favorably IF signal is true
2. Signal must be CREDIBLE: you must have incentive to follow through

Credibility devices: Irreversible investments (Tesla Gigafactory > VW's verbal claim)
```

### PARTS Framework (Changing the Game)

| P | A | R | T | S |
|:---:|:---:|:---:|:---:|:---:|
| **Players** | **Added Values** | **Rules** | **Tactics** | **Scope** |
| Add/remove | Make yourself indispensable | Change mode of competition | Change perceptions | Cross-game effects |
| NutraSweet/HSC | Card Game, burning cards | Kiwi Airlines, MCC clauses | New York Post, Ryanair/Aer Lingus | Sega 16-bit system |

### Added Value & Outside Options
- **Your profit** ≈ Your added value to the game
- **Maximize** by: raising your added value, raising your outside option, lowering others'
- Card game: equal red/black cards → competitive. Remove one black card → monopoly power

## Network Effects & Platforms

### Types
```
Same-Side: Users care about # users on THEIR side (WhatsApp, phone networks)
Cross-Side: Users care about # on OTHER side (iOS users ↔ app developers)
Most platforms: BOTH types
```

### Platform Strategy Triangle
```
        Create vibrant ecosystem
              /          \
             /            \
   Low incentive      Low incentive
   to SWITCH          to COMPETE
   (for participants)  (for rivals)
```

### Open vs. Closed Timing
```
Phase 1: OPEN → Establish dominance (Facebook Open Graph APIs)
Phase 2: CLOSE → Protect dominance (Facebook denying Vine API access)
```

### Chicken-or-Egg Solutions
Subsidize one side → Create standalone value → Leverage existing users → Acquire content
