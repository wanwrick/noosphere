## Framework 1: SOI Three Contexts Model

```
OPERATIONAL OPTIMIZATION  →  ORGANIZATIONAL TRANSFORMATION  →  SYSTEMS BUILDING
   Incremental                  Transitional                    Radical
   Insular                      Systemic emerging               Embedded
   Stand-alone                  Integrated                      Purpose-driven
   Technical                    Socio-technical                 Net positive
   Reducing harm                Creating benefit                Transforming
```

**Three Assessment Dimensions:**
| Dimension | Left Pole | Right Pole |
|-----------|-----------|------------|
| Scope | Insular (Scope 1&2 only) | Systemic (Scope 3+, value chain) |
| Integration | Stand-alone CSR dept | Embedded in all functions + exec comp |
| Approach | Technical solutions only | Socio-technical (governance, biz model) |

## Framework 3: LCA vs LCT

```
Raw Material → Manufacturing → Distribution → Use → End-of-Life
└──────────────────── System Boundary ──────────────────────────┘
```

| | LCA (Assessment) | LCT (Thinking) |
|---|---|---|
| Duration | Months | Hours to days |
| Data | Intensive, quantitative | Qualitative estimates |
| Use when | High-stakes, product comparisons | Screening, "what if" scenarios |

**Two Methods:** SETAC-EPA (process-based, narrow/accurate) vs I-O (economic, comprehensive/aggregated)

**Critical Scoping:** Functional Unit → System Boundary → Impact Categories → Allocation Rules

**Key Rule:** Avoid burden shifting (improving one stage while worsening another)

## Framework 4: Systems Thinking

| Concept | Definition | Example |
|---------|-----------|---------|
| Stocks | Accumulations that persist | CO2 in atmosphere |
| Flows | Rates of change | Emissions rate |
| Reinforcing Loop (+) | Exponential growth/collapse | Renewable adoption → cost reduction → more adoption |
| Balancing Loop (−) | Stabilization | Resource extraction → price increase → reduced demand |
| Time Delays | Actions ≠ immediate consequences | GHG today → climate impact decades later |

**System Archetypes:**
1. **Fixes That Fail** — Symptomatic fix creates worse side effects (Nike factory audits)
2. **Shifting the Burden** — Quick fix prevents fundamental solution (PR vs operational redesign)
3. **Tragedy of the Commons** — Individual rational actions degrade shared resources

## Framework 5: Value Creation Portfolio (Hart & Milstein 2003)

```
                    INTERNAL              EXTERNAL
            ┌──────────────────┬──────────────────┐
   TODAY    │ PRODUCTIVITY     │ INFO DISSEM.     │
   (0-18mo) │ Cost/risk reduc. │ Reputation/trust │
            │ Scope 1&2 intens.│ Disclosure qual. │
            ├──────────────────┼──────────────────┤
   TOMORROW │ DISCOVERY        │ OPP. FRAMING     │
   (2-5yr)  │ Pilots/new BMs   │ Coalitions/stds  │
            │ Capability build │ Market shaping   │
            └──────────────────┴──────────────────┘
```

**Common Pitfall:** Most companies overweight Today/Internal (efficiency) — check for portfolio balance.

## Framework 6: Materiality

| Type | Question |
|------|----------|
| **Financial Materiality** | How does this issue affect company finances? |
| **Impact Materiality** | How does the company affect society/environment? |
| **Double Materiality** | Both — highest priority (EU CSRD requires this) |

**Key Research Finding (Serafeim 2016):** Firms improving on *material* issues see financial gains; improvement on *immaterial* issues shows no effect.

## Framework 7: Circular Economy

```
Most Preferred ────────────────────────────── Least Preferred
REDUCE → REUSE → REPAIR → REMANUFACTURE → RECYCLE → TRASH
```

**Three Models:** Linear (take-make-dispose) → Circular (reuse-recycle) → Performance (service-based)

**Performance Examples:** Michelin tires-by-mile, Rolls Royce Power-by-Hour

|-----------|---------|-------|

## Analysis Checklist

- [ ] All 3 TBL dimensions (environmental, social, economic)
- [ ] All 3 Scopes analyzed (Scope 1, 2, 3)
- [ ] Company mapped to SOI framework with justification
- [ ] Peer benchmarking (2-3 competitors minimum)
- [ ] Both incremental AND transformational recommendations
- [ ] Business case (risks AND opportunities)
- [ ] Social dimensions (workforce, community, just transition)
- [ ] Evidence-based (not company PR)
- [ ] Sources cited

## Key Distinctions

| Concept | Strategic View | Common Misconception |
|---------|---------------|---------------------|
| Role vs. Responsibility | What company CAN uniquely do | What company SHOULD do generically |
| ESG vs. Strategy | Data toolkit for assessment | Strategy itself |
| Greenwashing vs. Evidence | Operational changes with metrics | PR without substance |
| Less Unsustainable vs. More Sustainable | Incremental harm reduction | Net positive transformation |
