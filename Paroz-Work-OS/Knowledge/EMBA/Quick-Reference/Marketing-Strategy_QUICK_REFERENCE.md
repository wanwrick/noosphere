## Core Concepts

```
Marketing Philosophy Evolution:
  Production → Product → Selling → Market Orientation
  "Make"       "Better"   "Sell"    "Sense & Respond"

Competitive Advantage Shift:
  Inside-Out (what can we make?) → Outside-In (what can we do for customers?)

JTBD: The JOB, not the customer, is the fundamental unit of analysis.
CDJ:  Funnel replaced by circular journey (awareness → consider → buy → experience → loyalty → advocacy)
```

## Jobs-to-be-Done Quick Guide

**Find Jobs by:**
1. Identify problems/unmet needs (non-consumption, work-arounds)
2. Combine existing solutions (clusters of desires)
3. Split existing solutions (underserved segments within categories)

**Product "Resume":**
- "Common" features = table stakes
- "Unique" features = differentiators
- "Don't Do" = features to avoid

## Experimentation Checklist

```
1. Form hypothesis (direction + variables)
2. Define DV (measured) and IV (changed)
3. Set up treatment and control groups
4. Demonstrate causation: correlation + time order + no confounds
5. Check internal validity (competing explanations ruled out?)
6. Check external validity (generalizable?)
```

---

## AI Implementation Framework

```
For any marketing AI use case, define:
  1. Data Inputs → 2. Model Selection → 3. Real-Time or Batch?
  4. Evaluation Metrics → 5. Deployment Method

AI Failure Types:
  Flawed Tech (learned wrong thing)
  Flawed Human (implemented wrong)
  Total Disaster (both)
```
