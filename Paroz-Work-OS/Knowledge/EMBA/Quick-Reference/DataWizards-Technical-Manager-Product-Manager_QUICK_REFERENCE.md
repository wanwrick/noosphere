# DataWizards Leadership Quick Reference Card

## 🎯 Time Allocation Rule
**80% Operational | 20% Strategic** (Mintzberg/Kotter)

---

## 📊 Strategic Planning Flow
```
Context Analysis → Synthesis → Define Direction → Take Action
```

### SWOT: The "3 Each" Rule
Identify exactly **3 make-or-break** items per quadrant (not everything important)

### Strategic Objectives: SMAC
- **S**pecific
- **M**easurable (What? When?)
- **A**ctionable (How? Who?)
- **C**ompatible

### Action Plan Formula
```
Objective → Strategic Thrust (12+ mo) → Action Plans (90-120 days)
Each Action: What + How + Who + When + Budget
```

---

## 👥 Leadership vs Management

| Need This? | Use |
|------------|-----|
| Predictability, order | **Management** (plan, organize, control) |
| Change, transformation | **Leadership** (vision, align, inspire) |

---

## 📝 User Story Template

```markdown
## Title: [Concise, descriptive]

## Desired Business Outcome
[action] to [result] [by/for/to/of] [object] so that [business value]

## Acceptance Criteria
- Measurable outcomes as bullets

## Technical Details
- Implementation approach

## Testing Scenarios
- Step-by-step test cases
```

### Subtask Format
**Input** → **Outcome** → **Notes**

## 💰 Compensation Case Structure

1. Executive Summary (3 bullets)
2. Market Analysis (benchmarks + gap)
3. Value Quantification (hours × rate × 1.4)
4. Retention Risk (% probability)
5. ROI Calculation
6. Implementation Steps

### Replacement Cost Formula
**150% of annual salary** = Recruitment + Productivity Loss + Business Disruption

### ROI Formula
```
ROI = (Replacement Cost × Retention Prob - Investment) ÷ Investment × 100
```

## 📅 Meeting Checklist

**Before**: Agenda + objectives + time bounds + pre-reads  
**During**: Start with objectives, process checks, involve everyone  
**After**: One-page summary with What/Who/When

---

## ⚠️ Warning Signs

### What Great GMs Do NOT Do
❌ Micro-manage  
❌ Easy route (across-the-board cuts)  
❌ Punish well-intentioned failure  
❌ Manage from office  
❌ Stop communicating in tough times

### Blind Spots
Career paths create gaps. Engage in ALL 10 operational duties regardless of comfort.

## 📞 Escalation Decision Tree

```
Issue identified
    ↓
Can I resolve in my authority? → Yes → Resolve
    ↓ No
Document: Issue + Impact + History + Ask
    ↓
Escalate with specific deadline
```
