## Project Options

```
MANAGEMENT CONSULTING PROJECT (MCP):
  → Real business problem/opportunity within a defined organization
  → Recommend a course of action for implementation

NEW VENTURE PROJECT (NVP):
  → Real business opportunity
  → Comprehensive business plan (new business, venture, or product)
```

---

## Four-Step Process

```
Step 1: PROPOSAL          Nov 25, 2024    Not graded (mandatory)
        Max 2 pages: client, problem, interest, value-add, research plan

Step 2: WORK PLAN         Jan 31, 2025    5% (project management)
        8-10 pages: objectives, timelines, framework/TOC, MBA concepts, scope

Step 3: REPORT/PLAN       June 2, 2025    75%
        Transmittal letter + Executive Summary + TOC + Body + Appendices
        SWOT/PEST in appendices only — apply findings in context

Step 4: PITCH             July 14, 2025   20%
        20 min + 10 min Q&A to Pitch Evaluator (plays a role)
```

---

## Key Rules

```
☐ Individual effort (rare 2-person exception)
☐ Analytical tools (SWOT, PEST) → appendices only, not body
☐ ChatGPT use must be cited; heavy reliance → risk failure
☐ Late penalty: 2% per day
☐ B = fully satisfactory; A = exceeds expectations
☐ Must apply MBA concepts from multiple courses
☐ Executive Summary = most important section ("the hook")
☐ Advisor = your client; manage the relationship
```

## Paroz's Project: The Regulated Innovator's Playbook

```
Client:    Questrade
Problem:   600+ Active Directory groups → access management complexity
Solution:  Four-role RBAC model
Value:     $1.2-1.5M annually | 42% IRR | 12-month payback
Impact:    70% admin cost reduction | Data users 28% → 70% | 3.5x faster decisions
Confidence: 97% success probability (Monte Carlo simulation)

MBA Concepts Applied:
  → Strategy META (PEST, Five Forces, VRIN)
  → Congruence Model (organizational misalignment)
  → IDEALS Framework (systematic problem diagnosis)
  → MIS (enterprise architecture, socio-technical systems)
  → Financial modeling (NPV, IRR, Monte Carlo)
```
