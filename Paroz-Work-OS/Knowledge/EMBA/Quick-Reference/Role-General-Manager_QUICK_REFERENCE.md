## Strategy Definition

```
Strategy = An integrated set of choices for future success:
  → WHY we exist
  → WHAT we do (products, services)
  → FOR WHOM (market segments, geographies)
  → HOW we make money (profit model)
  → HOW we deliver (internal, JVs, licensing, alliances, acquisitions)
  → WHEN (sequence and staging)
```

## The GM's 80-Hour Week

```
60 hours OPERATIONAL:              20 hours STRATEGIC:
  • Meeting budget targets           • Building the future
  • HR leadership (mentoring)        • Strategy development
  • Running meetings/committees      • Major change projects
  • Fire-fighting/problem-solving    • New market/product initiatives
  • Operations oversight
  • Communications
  • Sales/marketing support
  • Board/boss management
  • External stakeholders
```

## Strategic vs Operational Planning

```
STRATEGIC PLANS:                    OPERATING PLANS:
  Time: 3-5-10 years                 Time: 12 months
  Budget: Investment                  Budget: Operating
  Vehicle: Large change projects      Vehicle: Routine procedures
  Update: Quarterly (best practice)   Update: Monthly
  Focus: Grow, build, transform       Focus: Deliver today efficiently
```

## Six Takeaways on Change & Execution

```
1. Strategic planning = game plan for change
2. Projects = vehicle for change
3. Timing and sequencing are critical
4. Establish the winning conditions (guidance, speed, momentum)
5. Execution is key to make it happen
6. Disciplined, courageous leadership required
```

## Four Levels of Uncertainty

```
Level 1: Clear-Enough Future    → Residual uncertainty irrelevant
Level 2: Alternate Futures      → Few discrete scenarios
Level 3: Range of Futures       → Many variables, many scenarios
Level 4: Unpredictable          → True uncertainty
```

## Strategic Planning Presentation Template

```
 1. Executive Summary
 2. Environmental / Industry / Competitive factors (2-3 slides)
 3. Major Strategic Issues — SWOT (1 slide)
 4. Strategic / Operational Health matrix (1 slide)
 5. Core Competences (1-2 slides)
 6. Culture assessment (1 slide)
 7. Vision, Mission, Objectives (3 slides)
 8. Positioning statement (1-2 slides)
 9. KPI Scorecard (1 slide)
10. Strategies / Action Plans (6-7 slides)
11. Requirements from other BUs (1 slide)
12. Major programs GANTT chart (1 slide)
13. HR Requirements (1 slide)
14. Financial Impact (1 slide)
15. Major Risks (1 slide)
```
