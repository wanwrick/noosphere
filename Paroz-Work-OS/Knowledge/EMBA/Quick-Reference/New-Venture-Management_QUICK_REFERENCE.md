## Opportunity Screening Framework

```
Problem/Customer          Timing
  ☐ Identified/understood   ☐ Macro favorable
  ☐ Worth solving            ☐ Industry favorable
  ☐ Large/growing market     ☐ Competitive forces OK
                             ☐ Limited complexity

Money Making              Team
  ☐ Multiple revenue streams ☐ Know it all
  ☐ Big margins              ☐ Know everyone
  ☐ Early cash flows         ☐ Are known for everything
  ☐ Worthwhile market        ☐ Right fit for opportunity
```

## Lean Startup Process

```
1. Develop Vision (ideation)
2. Translate to Falsifiable Hypotheses
3. Build MVP (minimum viable product)
4. Test → Feedback
5. Persevere / Pivot / Perish
6. Repeat until Product-Market Fit
```

**"Lean" ≠ cheap.** Lean = avoid waste (validate before scaling).

## Business Model Hypotheses (4 Elements)

| Element | Key Questions |
|---------|-------------|
| **Value Proposition** | Unmet needs? Segments? Differentiation? Pricing? |
| **Go-To-Market** | Channels? CAC? Viral? Chasm crossing? |
| **Tech & Operations** | Build vs buy? Key risks? Scalability? |
| **Cash Flow** | Revenue model? Unit economics? Breakeven? |
