## Demand & Supply Essentials

### Demand Function
```
Qd = a - bP     →     P = (a/b) - (Qd/b)
```

### Supply Function  
```
Qs = α + βP     →     P = -(α/β) + (Qs/β)
```

### Finding Equilibrium
```
Set Qd = Qs  →  Solve for P*  →  Plug P* back to get Q*
```

---

## Slides vs. Shifts

| Change | What Happens | Triggered By |
|--------|-------------|--------------|
| **SLIDE** | Move along curve | Change in price of that good |
| **SHIFT** | Entire curve moves | Anything else |

**Rule**: Price of the good → SLIDE. Everything else → SHIFT.

---

## Demand Shifters (shift the demand curve)

| Shifter | ↑ Causes |
|---------|----------|
| Income (normal good) | Demand ↑ (shift right) |
| Income (inferior good) | Demand ↓ (shift left) |
| Price of substitute | Demand ↑ (shift right) |
| Price of complement | Demand ↓ (shift left) |
| Advertising/preferences | Depends on direction |
| Population | Demand ↑ (shift right) |

---

## Supply Shifters (shift the supply curve)

| Shifter | ↑ Causes |
|---------|----------|
| Input prices | Supply ↓ (shift left) |
| Technology improvements | Supply ↑ (shift right) |
| Regulations | Supply ↓ (shift left) |
| Number of firms | Supply ↑ (shift right) |
| Taxes | Supply ↓ (shift left) |

## Price Elasticity

### Formula
```
ε = (%ΔQ) / (%ΔP) = (ΔQ/ΔP) × (P/Q)
```

### Interpretation
| Magnitude | Type | Revenue if P↑ |
|-----------|------|---------------|
| \|ε\| > 1 | Elastic | Revenue ↓ |
| \|ε\| < 1 | Inelastic | Revenue ↑ |
| \|ε\| = 1 | Unit elastic | Revenue unchanged |

---

## Market Mechanism

| Condition | Result |
|-----------|--------|
| P > P* (equilibrium) | Excess supply → Price falls |
| P < P* (equilibrium) | Excess demand → Price rises |
| P = P* | Market clears, stable |

## Game Theory Quick Guide

### Payoff Matrix Convention
- **Row player's payoff listed FIRST**: (Row, Column)
- Example: Cell shows (5, 3) → Row gets 5, Column gets 3

### Finding Nash Equilibrium
1. For each cell: Is Row playing best response given Column's choice?
2. For each cell: Is Column playing best response given Row's choice?
3. **Nash equilibrium** = cells where BOTH answer yes

### Dominant Strategy
- **Dominant**: Best choice NO MATTER what opponent does
- **Dominated**: Never optimal, always beaten by another strategy
- **Rule**: If you have a dominant strategy, PLAY IT

---

## Prisoner's Dilemma Checklist

✓ Both can cooperate or defect  
✓ Dominant strategy for both = defect  
✓ (Defect, Defect) is Nash equilibrium  
✓ (Cooperate, Cooperate) would be better for both  
**→ Individual rationality leads to collective harm**

## Repeated Games

| Horizon | Outcome |
|---------|---------|
| **Finite (known end)** | Defect every period (unraveling) |
| **Infinite/Uncertain end** | Cooperation possible |

## Worked Example: Equilibrium

**Given**: Qs = 88 + 40P, Qd = 286 - 20P

**Step 1**: Set Qs = Qd
```
88 + 40P = 286 - 20P
60P = 198
P* = $3.30
```

**Step 2**: Find Q*
```
Q* = 88 + 40(3.30) = 220
```

## Worked Example: Elasticity

**Given**: 3% price increase → 6% quantity decrease

```
εd = -6% / 3% = -2
```

**Magnitude** = 2 > 1 → **Elastic demand**  
**Implication**: Price increase → Revenue decreases

## Common Mistakes to Avoid

❌ Confusing slides and shifts  
❌ Forgetting row player payoff is FIRST  
❌ Thinking Nash equilibrium is always the "best" outcome  
❌ Forgetting elasticity is negative (use magnitude)  
❌ Applying game theory when firms are price-takers  
❌ Assuming finite repeated games sustain cooperation
