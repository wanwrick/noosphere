## Three Types of Digital Strategy

```
1. CUSTOMER ENGAGEMENT  — Omnichannel, personalization, loyalty, rapid response
2. DIGITAL SOLUTIONS    — Integrate products + services + information across lifecycle
3. OPERATIONAL EXCELLENCE — Streamline processes (now the minimum requirement)
```

---

## Digital Definitions

```
DIGITIZATION      → Analog to digital (paper → electronic documents)
DIGITALIZATION    → Manual to digital processes (efficiency via automation)
DIGITAL TRANSFORM → Strategy + Structure + Culture change (new revenue/value)

We digitize DATA, digitalize PROCESSES, digitally transform the BUSINESS.
```

CLASSIC:                              MODERN:

## Case Memo Format (Strict 2-Page)

```
TO: Decision Maker | FROM: Team | SUBJECT: 3-5 words

ISSUES        — Exactly 5 issues (3-5 word heading + 20-30 word description each)
PROBLEM       — Strategic problem + decision question (40-60 words)
ALTERNATIVES  — Exactly 3 mutually exclusive solutions (20-30 words each)
CRITERIA      — Exactly 3 evaluation criteria (20-30 words each)
EVALUATION    — Pros/cons of each alt vs. each criterion + recommendation (120-140 words)
ACTIONS       — Exactly 3 implementation actions (20-30 words each)
```
