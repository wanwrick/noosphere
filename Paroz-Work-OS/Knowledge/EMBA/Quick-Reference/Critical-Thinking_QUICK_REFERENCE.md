## The Method: Context + IDEALS

```
1. CONTEXT    — Macro (PESTLE) + Micro (company, actors, biases)
2. IDENTIFY   — Immediate Problem (gap: Current → Desired State) + Big Picture Problem
3. DETERMINE  — 3 Root Causes (Congruence Model + evidence)
4. ENUMERATE  — 3 Solution Options (how each bridges the gap)
5. ASSESS     — Best option (desirable AND feasible)
6. LIST       — Reasons why recommended > rejected alternatives
7. SELF-CORRECT — Objections, risks, mitigations, net benefits
```

---

## Decision Stakes: 10-10-10

```
Will this matter in 10 hours? 10 weeks? 10 YEARS?
  + Worst case: How bad? How likely?
  + Best case: How good? How possible?
  + How reversible?
If best case possible + worst case manageable + reversible → DECIDE.
```

## Information Sorting (3 Questions)

| Step | Ask | Purpose |
|------|-----|---------|
| 1 | What do we **KNOW** (and how)? | Establish facts |
| 2 | What do we **ASSUME** (is it valid)? | Challenge assumptions |
| 3 | What **DON'T WE KNOW** (that matters)? | Find blind spots |

## Executive Summary Test

```
Three-part test: Neutrality + Clarity + Specificity
1. SITUATION — Neutral facts (no editorializing)
2. PROBLEMS — Immediate + Big Picture (neutrally framed)
3. RECOMMENDATION — Specific enough to understand without full analysis
```

## System 1 vs System 2

| System 1 (FAST) | System 2 (SLOW) |
|-----------------|-----------------|
| Intuition, pattern recognition | Critical thinking, deliberate analysis |
| Low-stakes, familiar | Moderate-to-high-stakes |

## After-Action Review

```
1. What was supposed to happen?
2. What actually happened?
3. What went well? Why?
4. What didn't go well? Why?
5. Keep doing?
6. Do differently?
```
