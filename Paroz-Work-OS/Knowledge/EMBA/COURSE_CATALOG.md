## How to Use This Catalog

1. **Find the relevant course(s)** for your task using the Task Router at the bottom
2. **Read the SKILL file** for frameworks and theory
3. **Read the QUICK_REFERENCE** for a condensed cheat sheet
4. **For operational depth**, read specific course folder files (Excel models, case studies, Paroz's work)
5. **Cross-reference multiple domains** when a task spans areas

**Base Paths (Work OS internal):**
- SKILL files: `Knowledge/EMBA/Skills/<Name>.SKILL.md`
- Quick-Reference cards: `Knowledge/EMBA/Quick-Reference/<Name>_QUICK_REFERENCE.md`

**Base Paths (External course materials):**
- Course folders: `C:\Users\paroz\OneDrive\Desktop\Smith Cornell EMBA Classes\<Course-Name>\` (Title-Case-With-Hyphens)
- Program folders (Simulation, Individual Project): `Smith Cornell EMBA Classes\_Program\`
- Category folders: `_Career\`, `_Claude-Reference\`, `_Program\`, `_Projects\`, `_Technical\`

**Naming Convention:** All folders use Title-Case-With-Hyphens (e.g., `Corporate-Governance/`, `Session-01/`)
**Internal Structure:** Sessions/ → Session-01..., Readings/, Assignments/, Projects/, Slides/, Resources/
