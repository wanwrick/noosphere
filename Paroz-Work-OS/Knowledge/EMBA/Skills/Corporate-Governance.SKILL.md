# 2. CORE CONCEPTS

## 2.1 The Fundamental Governance Question

**The Agency Problem**: How do we ensure that managers (agents) act in the best interests of shareholders (principals) when ownership and control are separated?

This single question drives the entire field of corporate governance.

## 2.2 Agency Theory (Jensen & Meckling)

**Definition**: The separation of ownership and control creates inherent conflicts of interest between shareholders and managers.

**Agency Costs** (the price paid for the separation):
1. **Monitoring Costs**: Board oversight, audits, compliance, internal controls
2. **Bonding Costs**: Contractual restrictions, executive commitments, equity stakes
3. **Residual Loss**: Value destroyed despite monitoring and bonding

**Total Agency Costs** = Monitoring + Bonding + Residual Loss

**Key Insight**: Agency costs can never be eliminated entirely; governance structures seek to minimize them efficiently.

## 2.3 Value Maximization (Jensen, 2001)

**Core Thesis**: The corporate objective function should be to maximize long-term firm value (sum of all financial claims).

**Firm Value** = Debt + Equity + Preferred Stock + Warrants + Other Claims

**Critical Distinction**:
- **Short-term stock price**: Subject to sentiment, bubbles, manipulation
- **Long-term market value**: Reflects true economic value creation

**The Multiple Objectives Problem**: You cannot maximize in more than one dimension simultaneously. Having multiple objectives (satisfy shareholders AND employees AND communities) is equivalent to having no objective at all.

**Jensen's Quote**: "200 years of work in economics and finance indicates that social welfare is maximized when all firms in an economy maximize total firm value."

## 2.4 Enlightened Value Maximization (Jensen's Synthesis)

**Definition**: Long-term value maximization that recognizes stakeholder relationships as instrumental to that goal.

**Key Principles**:
1. Single-valued objective (long-term firm value) provides clear decision criterion
2. Stakeholder wellbeing is a MEANS to value maximization, not an END
3. Managers must understand how to create value with each stakeholder group
4. Trade-offs between stakeholders must be made transparently

**The Critical Distinction**:
- **Pure Stakeholder Theory**: Satisfy all stakeholders as ends in themselves
- **Enlightened Value Maximization**: Manage stakeholder relationships to maximize long-term value

## 2.5 Stakeholder Theory Compatibility (Wallace, 2003)

**Empirical Finding**: Value maximization and stakeholder investment are complementary, not contradictory.

**Key Research Results**:
1. Companies must CREATE value before they can distribute it to stakeholders
2. Stakeholder investment adds value up to a point, then diminishes
3. Companies in the bottom quartile of MVA (value destroyers) are MORE likely to have excessive stakeholder spending
4. Sustainable stakeholder investment requires profitable operations first

**The Sequence**: Profitability → Stakeholder Investment → Sustainable Value Creation

## 2.6 Corporate Governance 2.0 (Subramanian, 2015)

**Three Foundational Principles**:

### Principle 1: Long-Term Board Authority
- End earnings guidance; replace with long-term goals (market share, new products, revenue from new markets)
- Bring back "dismantlable staggered boards" (three-year terms with shareholder override)
- Allow exclusive forum provisions (prevent plaintiff shopping)

### Principle 2: Best People in the Boardroom
- Require meaningful third-party director evaluations (not internal reviews)
- Consider proxy access as a backstop (ensures expertise when boards fail)
- Focus on skills-based composition over box-ticking diversity

### Principle 3: Orderly Shareholder Voice
- Boards should guarantee reasonable processes for shareholder decisions
- Avoid scorched-earth defenses (poison pills, staggered boards combined)
- Create "advance notice" pills (exempt shareholders who disclose intent within 2 days)

**Governance 2.0 Comparison Matrix**:

| Issue | Shareholder Activists | Board Defenders | Gov 2.0 |
|-------|----------------------|-----------------|---------|
| Earnings Guidance | Yes | Mixed | Replace with long-term goals |
| Staggered Boards | No | Yes | Dismantlable stagger |
| Age/Term Limits | Yes | No | Meaningful evaluations |
| Proxy Access | Yes | No | Consider as backstop |
| Defensive Measures | No | Yes | "Orderly voice" |
| Poison Pills | No | Yes | "Advance notice" pill |

# 3. FORMULAS & CALCULATIONS

## 3.1 Value-Based Management Metrics

### Economic Value Added (EVA)

**Formula**:
```
EVA = NOPAT - (Invested Capital × WACC)
```

**Variables**:
- **NOPAT**: Net Operating Profit After Tax = EBIT × (1 - Tax Rate)
- **Invested Capital**: Total Assets - Non-Interest-Bearing Current Liabilities
- **WACC**: Weighted Average Cost of Capital

**Interpretation**: Positive EVA indicates value creation; negative EVA indicates value destruction

**When to Use**: Evaluating whether management generates returns above the cost of capital

**Common Mistake**: Using accounting profit instead of economic profit (ignores cost of equity)

### Market Value Added (MVA)

**Formula**:
```
MVA = Market Value of Firm - Invested Capital
MVA = (Share Price × Shares Outstanding + Market Value of Debt) - Book Value of Capital
```

**Interpretation**: The wealth created (or destroyed) since the company's founding

**When to Use**: Assessing cumulative value creation over time

### Return on Capital (ROC)

**Formula**:
```
ROC = NOPAT / Invested Capital
```

**Value Creation Rule**:
- If ROC > WACC → Value created
- If ROC < WACC → Value destroyed
- If ROC = WACC → No value created

### Total Shareholder Return (TSR)

**Formula**:
```
TSR = (Ending Price - Beginning Price + Dividends) / Beginning Price
```

**Annualized TSR**:
```
Annualized TSR = [(1 + TSR)^(1/n)] - 1
```
Where n = number of years

### Relative TSR

**Calculation**: Company TSR compared to peer group or index (e.g., S&P 500) over same period

**Percentile Ranking**: Where company falls in distribution of peer TSR

**Best Practice**: Use relative TSR in compensation to isolate management contribution from market movements

## 3.2 Compensation Calculations

### Option Value (Black-Scholes Conceptual)

**Key Drivers**:
- Stock price vs. strike price
- Time to expiration (longer = more value)
- Volatility (higher = more value)
- Risk-free rate
- Dividend yield

**Vega Effect**: Options increase in value with volatility, potentially encouraging risky behavior

### Pay-Performance Sensitivity

**Formula**:
```
Pay-Performance Sensitivity = Change in CEO Wealth / Change in Shareholder Wealth
```

**Interpretation**: How much CEO wealth changes per $1,000 change in firm value

### Compensation Mix Analysis

**Total Compensation** = Base Salary + STI + LTI + Benefits + Perquisites

Where:
- **STI**: Short-Term Incentives (annual cash bonus)
- **LTI**: Long-Term Incentives (equity-based awards)

**Fixed vs. Variable Ratio**:
```
Variable Percentage = (STI + LTI) / Total Compensation
```

**Best Practice**: Higher variable percentage (60-80%) for senior executives

## 3.3 Ownership & Voting Analysis

### Dual-Class Voting Power

**Formula** (when Class B has 10x votes):
```
Voting Power = (Class A Shares × 1 + Class B Shares × 10) / Total Votes
Economic Ownership = (Class A Shares + Class B Shares) / Total Shares
```

**Wedge**: Difference between voting power and economic ownership

**Example (Shake Shack)**:
- Danny Meyer controls 58% voting power through Class B stock
- Engaged Capital's 6.6% economic stake = only 3.9% voting power
- Wedge enables control without proportional economic exposure

### Proxy Contest Math

**Threshold for Control**: Typically >50% of shares voted

**ISS Influence**: ISS recommendations influence ~15-25% of institutional votes

**Settlement Rate**: 60% of proxy contests end in negotiated settlements

# 4. FRAMEWORKS & METHODOLOGIES

## 4.1 Executive Compensation Evaluation Framework

**Step 1: Governance Assessment**
- Is the compensation committee truly independent?
- Are there conflicts of interest (family members, interlocking directorships)?
- Was an independent compensation consultant used?
- Was there comparable company analysis?

**Step 2: Alignment Analysis**
- Do metrics align with long-term value creation?
- Are targets absolute or relative to peers?
- Are there profitability gates (must be profitable to vest)?
- What is the mix of financial vs. operational metrics?

**Step 3: Structure Evaluation**
- Fixed vs. variable ratio appropriate for role?
- Short-term vs. long-term balance?
- Cash vs. equity balance?
- Individual vs. group metrics?

**Step 4: Risk Assessment**
- Does plan encourage excessive risk-taking?
- Are there clawback provisions?
- What is the holding period post-vesting?
- Are there caps on payouts?

**Step 5: Stakeholder Impact**
- How does plan affect employees, customers, communities?
- Does it encourage stakeholder exploitation for short-term gains?
- Is there alignment with ESG commitments?

**Decision Framework**:
```
IF (Board Independent) 
   AND (Metrics Relative to Peers) 
   AND (Profitability Required)
   AND (Stakeholder Impact Considered)
   THEN → Consider Approval
ELSE → REJECT and Demand Governance Reform
```

## 4.2 Board Composition Assessment Framework

**Independence Analysis**:
1. Count truly independent directors (no material relationships)
2. Verify compensation committee independence
3. Check for family ties, interlocking directorships
4. Assess CEO-Chair separation

**Expertise Mapping**:
| Director | Industry | Finance | Risk | Operations | Technology | Legal |
|----------|----------|---------|------|------------|------------|-------|
| Name 1   |    X     |         |  X   |            |            |       |
| Name 2   |          |    X    |      |            |      X     |       |

**Key Questions**:
- Does expertise match company's strategic challenges?
- Are there critical gaps in domain knowledge?
- Is there cognitive diversity (not just demographic)?

**Corporate Governance 2.0 Criteria**:
- [ ] Meaningful third-party evaluations conducted?
- [ ] Skills-based composition (not box-ticking)?
- [ ] Directors who have been there longer than CEO can challenge?
- [ ] Succession planning for board roles?

## 4.3 Activist Response Framework

**Step 1: Charge Validation**
- Are activist charges factually accurate?
- Is there a significant performance gap vs. peers?
- Do financial metrics support the criticism?

**Step 2: Credibility Assessment**
- Does activist have meaningful stake (>5%)?
- Track record of successful campaigns?
- Quality of operational improvement thesis?
- ISS likely to support?

**Step 3: Board Capacity Evaluation**
- Does current board have expertise to address issues?
- Are there obvious composition gaps?
- Has board been refreshed recently?

**Step 4: Structural Defense Inventory**
- Dual-class structure?
- Staggered board?
- Poison pill in place?
- Exclusive forum provision?

**Step 5: Response Strategy Selection**:

| Situation | Recommended Response |
|-----------|---------------------|
| Valid charges + Weak board | Proactive refresh (add expertise) |
| Valid charges + Strong board | Operational plan with accountability |
| Invalid charges + Strong defenses | Defend and communicate |
| Invalid charges + Weak defenses | Settle for stability |

**Settlement Considerations**:
- 60% of proxy contests end in settlement
- Settlements preserving structural defenses often "fall short"
- Best outcome: operational improvement + governance reform

## 4.4 Risk Management Three Lines of Defense

**First Line**: Business operations and management
- Day-to-day risk ownership
- Internal controls
- Policy compliance

**Second Line**: Risk management and compliance functions
- Independent risk assessment
- Policy development
- Monitoring and testing

**Third Line**: Internal audit
- Independent assurance
- Reports to audit committee
- Tests first and second lines

**Board Risk Committee Responsibilities**:
- Oversee risk appetite framework
- Monitor emerging risks
- Ensure adequate risk expertise
- Review stress test results

**SVB Failure Lesson**: All three lines failed when:
- First line (management) made concentrated bets on long-dated securities
- Second line (CRO position vacant 9 months) couldn't provide oversight
- Third line (internal audit) failed to escalate
- Board risk committee (lacked banking expertise) couldn't challenge

# 5. KEY RELATIONSHIPS & INSIGHTS

## 5.1 Core Theoretical Tensions

### Shareholder vs. Stakeholder Primacy
- **Shareholder View**: Maximize shareholder value; stakeholders protected by contracts
- **Stakeholder View**: Balance all constituent interests as ends in themselves
- **Enlightened View**: Maximize long-term value BY managing stakeholder relationships

**Resolution**: Jensen's enlightened value maximization provides single objective (long-term firm value) while requiring effective stakeholder management as means to that end.

### Short-Term vs. Long-Term Orientation
- **Short-term pressure**: Quarterly earnings, activist demands, stock price volatility
- **Long-term needs**: R&D investment, capability building, stakeholder relationships
- **Gov 2.0 Solution**: End earnings guidance, allow dismantlable staggers, long-term goals

### Board Stability vs. Accountability
- **Stability benefits**: Institutional knowledge, strategic continuity, challenge CEO
- **Accountability benefits**: Fresh perspectives, shareholder responsiveness, prevent entrenchment
- **Gov 2.0 Solution**: Staggered boards that can be "dismantled" by shareholders if needed

## 5.2 Cause-Effect Relationships

**Captured Board → Corrupted Compensation**
- Board independence determines compensation quality
- Family members on compensation committee = conflict
- Even well-designed plans fail with captured oversight

**Dual-Class + Staggered Board → Maximum Entrenchment**
- Separates voting power from economic interest
- Blocks market discipline despite underperformance
- Activists cannot gain control even with valid charges

**Absolute Metrics → Market Beta Reward**
- Absolute market cap targets reward market movements, not management
- Rising tide lifts all boats
- Relative metrics isolate management contribution

**Revenue Without Profit Gates → Value Destruction**
- Incentivizes growth at any cost
- Encourages negative NPV projects
- Creates "stakeholder arbitrage" (transfer value from stakeholders to hit targets)

## 5.3 Second-Order Insights

**"Irreplaceability" is a Governance Failure**
- If a company depends entirely on one person, succession planning has failed
- Should demand succession milestones, not reward dysfunction
- Board's fiduciary duty includes developing leadership pipeline

**Past Plan Success ≠ Future Plan Validity**
- Survivorship bias: only visible successes survive
- Correlation ≠ causation: market conditions may explain success
- Founder motivation: intrinsic mission may dominate extrinsic incentives

**Governance Theater vs. Governance Substance**
- Board refreshes without addressing structural defenses = theater
- "Meaningful evaluation" by internal parties = theater
- Third-party evaluations with real consequences = substance

**Alignment Without Expertise Creates Dangerous Blind Spots**
- Aligned but captured boards approve flawed plans
- Compensation committee expertise matters
- Independence + expertise = effective governance

# 6. PRACTICAL APPLICATION

## 6.1 Case Analysis Methodology

**Step 1: Frame the Governance Question**
- What is the fundamental agency problem in this situation?
- Who are the principals and agents?
- What are the conflicts of interest?

**Step 2: Apply Theoretical Framework**
- Jensen: Does this maximize long-term firm value?
- Wallace: Is stakeholder investment sustainable?
- Gov 2.0: Does structure balance long-term authority with accountability?

**Step 3: Assess Board Effectiveness**
- Independence (real, not nominal)
- Expertise (matches strategic challenges)
- Evaluation (meaningful third-party)

**Step 4: Evaluate Incentive Alignment**
- Do metrics drive value creation?
- Are there profitability gates?
- Is measurement absolute or relative?

**Step 5: Consider Stakeholder Impact**
- Beyond shareholders, who is affected?
- Is plan sustainable across stakeholder groups?
- Wallace test: Does value creation precede stakeholder spending?

**Step 6: Develop Recommendation**
- If approve: what conditions?
- If reject: what alternatives?
- What governance reforms needed?

## 6.2 Applying to Real Cases

### Tesla CEO Compensation Analysis

**Key Issues**:
- $55B potential payout (extreme magnitude)
- Absolute metrics (market cap, revenue, EBITDA)
- Board independence compromised (Kimbal Musk on comp committee)
- No profitability gates required
- No succession milestones

**Framework Application**:
| Framework | Assessment |
|-----------|------------|
| Jensen (Value Max) | Fails - absolute metrics reward market beta |
| Wallace (Stakeholder) | Fails - no stakeholder impact consideration |
| Gov 2.0 | Fails - board not independent, no meaningful evaluation |
| Groysberg (Comp Design) | Fails - no relative metrics, no profitability gates |

**Correct Answer**: REJECT as proposed; condition approval on governance reform

### Shake Shack Proxy Battle Analysis

**Engaged Capital's Charges**:
1. 790bp gross margin decline since 2018
2. ROC collapse from 30% to ~0%
3. Management lacks multi-unit scaling expertise
4. Board lacks industry expertise

**Structural Defenses**:
- Dual-class stock: Danny Meyer controls 58% voting power
- Staggered board: Only 4 directors up for election annually
- Engaged Capital's 6.6% economic stake = only 3.9% voting power

**Board Composition Problem**:
- Only 2 of 12 directors (16.7%) have restaurant operations experience
- Board optimized for fine dining heritage, not QSR scaling

**Framework Application**:
| Framework | Assessment |
|-----------|------------|
| Kim Ch. 7 (Activism) | Charges valid - significant deviation from value max |
| Gov 2.0 Principle 2 | Fails - not best people in boardroom |
| Gov 2.0 Principle 3 | Fails - structural defenses block orderly voice |

**Outcome**: Settlement "fell short for shareholders" per CNBC - operational improvements without governance reform

### Silicon Valley Bank Failure Analysis

**Three Lines of Defense Failure**:
1. **First Line (Management)**: Concentrated bets on long-dated securities
2. **Second Line (Risk)**: CRO position vacant April 2022 - January 2023
3. **Third Line (Audit)**: Failed to escalate concentration risk
4. **Board**: Risk committee lacked banking expertise

**Fed's Post-Mortem**:
"Failed because of a textbook case of mismanagement... senior leadership failed to manage basic interest rate and liquidity risk. Its board of directors failed to oversee senior leadership and hold them accountable."

**Key Governance Failures**:
- No CRO during critical period
- Risk committee without banking experts
- ALCO failed to catch duration mismatch
- Board finance committee lacked expertise to challenge

**Framework Application**:
| Framework | Assessment |
|-----------|------------|
| Gov 2.0 Principle 2 | Fails - risk committee without banking experts |
| Jensen (Value Max) | Fails - long-term value destroyed by short-term yield chasing |
| Three Lines of Defense | All three lines failed simultaneously |

## 6.3 Common Analysis Mistakes to Avoid

1. **Accepting premises without challenge**: Question "irreplaceability," "market determines pay," "founder vision"

2. **Confusing correlation with causation**: Prior plan success doesn't validate current plan

3. **Ignoring governance conflicts**: Board relationships, compensation consultant selection, interlocking directorships

4. **Incomplete agency analysis**: Consider majority-minority, debt-equity, temporal conflicts

5. **Narrow shareholder focus**: Stakeholder impacts matter for long-term value per Wallace

6. **Binary thinking**: Alternatives exist beyond simple approve/reject

7. **Conflating market cap with value creation**: Market cap can increase through multiple expansion without real value creation

8. **Missing structural entrenchment effects**: Dual-class + staggered board = maximum protection against accountability

# 11. THE BIG QUESTIONS (Professor Kingsley's Emphasis)

Return to these fundamental questions when analyzing any governance situation:

1. **Agency Problem**: How do we align manager and owner interests?

2. **Board Effectiveness**: What makes boards succeed or fail?

3. **Compensation Design**: How do we incentivize without distorting?

4. **Shareholder vs. Stakeholder**: Can we serve both? (Answer: Yes, through enlightened value maximization)

5. **Short vs. Long Term**: How do we balance temporal pressures?

6. **Independence vs. Expertise**: What happens when we have one without the other?

7. **Protection vs. Accountability**: How do we give boards time to execute while maintaining shareholder recourse?
