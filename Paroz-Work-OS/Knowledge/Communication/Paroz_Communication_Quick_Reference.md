# Paroz Communication Protocol - Quick Reference Guide

## 🎯 One-Page Decision Guide

### Email Length Rules
- **Routine:** 30-75 words → Direct answer + action + thanks
- **External:** 50-100 words → Purpose + attachment + help offer
- **Leadership:** 400-700 words → Get review before sending

### The Power Frameworks

**PREP** (For Any Response)
```
Point → Reason → Example → Point
"We need X. Because Y. Last week Z happened. Therefore X."
```

**SUCCESS** (For Memorable Messages)
```
Simple | Unexpected | Concrete | Credible | Emotional | Stories
Check: Is it sticky? Will they remember?
```

**SBI** (For Feedback)
```
Situation → Behavior → Impact
"Yesterday... → You did... → Which caused..."
```

### Subject Line Formulas
- Decision: `[DECISION BY DATE] Topic - Impact`
- Action: `[ACTION REQUIRED] Task - Deadline`  
- Update: `[Project] Status: 🟢🟡🔴 - Key Point`
- Escalation: `[ESCALATION] Blocker - Need by [Date]`

### Meeting Formula
- **T-24h:** Send agenda
- **T-0:** Start on time, end on time
- **T+4h:** Send summary with actions

### Presentation Structure
1. **Open:** Start with conclusion (not agenda)
2. **Middle:** Stories first, data second (3:1 ratio)
3. **Close:** Bold call-to-action

### Q&A Recovery Phrases
- Don't know: "Great question. Here's what I know... I'll follow up by [time]."
- Challenged: "I appreciate that perspective. My data shows..."
- Dominated: "Important point. Let's hear from others."

### Stakeholder Emails

**Executive (BLUF):**
```
Decision required: [1 sentence]
Recommendation: [Your pick]
Options: [Table]
Impact of delay: [Risk]
```

**Team Update:**
```
Status: 🟢 Green
This week: ✅ [Done]
Next week: 🎯 [Focus]
Blockers: [Issue + fix]
```

### The 5 Non-Negotiables
1. ✓ What, who, when (every action)
2. ✓ Stories > Data (3:1 ratio)
3. ✓ We not they (team language)
4. ✓ BLUF (answer upfront)
5. ✓ Bold next action (every close)

### Presence Checklist
- [ ] Confidence without arrogance
- [ ] Listen-to-learn orientation
- [ ] Camera on, eye level
- [ ] No weak language (maybe, I think)
- [ ] Stand for energy

### Daily Habits
- Morning: Clear urgent emails (<4h response)
- Meetings: PREP all responses
- Closes: Bold the next action
- Stories: Lead with human impact

## 🔧 Fix-It Phrases

**Instead of:** "I think maybe we should..."
**Say:** "I recommend we..."

**Instead of:** "Sorry for the delay"
**Say:** "Thanks for your patience"

**Instead of:** Long explanation
**Say:** PREP structure

**Instead of:** "Does anyone have questions?"
**Say:** "The question I often get is..."

## 📊 Ratios to Remember

- **70%** emails under 75 words
- **3:1** stories to data
- **50%** less text on virtual slides
- **10-80-10** presentation time (open-middle-close)
- **40-40-20** Pathos-Logos-Ethos in persuasion

---

## ⚡ Emergency Protocols

### When Put on Spot
→ Use PREP, buy time with "Great question..."

### When Technical for Business Audience
→ Lead with business impact, technical details in appendix

### When Meeting Goes Off-Rails
→ "Let's table that. Our objective today is..."

### When Email Chain Explodes
→ "Let's align on a call. I'll send invite."

### When Presenting to Hostile Audience
→ Acknowledge concerns upfront, use SBI for objections
