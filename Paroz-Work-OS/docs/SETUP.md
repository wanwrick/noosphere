# Work OS Setup Guide

> How to get the full Work OS running on a new machine (e.g., work laptop) in Claude Code or Cowork.

---

## Quick Start (5 Minutes)

1. Unzip the Work OS folder to your desktop or preferred location
2. Open the folder in Claude Code or Cowork
3. The system is self-contained: all Knowledge files, Templates, Workflows, and Frameworks are embedded

That's it. The system works immediately with all EMBA knowledge, frameworks, and reference materials.

### Without Skills Installed

The Work OS still works well without skills installed. The embedded Knowledge files cover:
- 8 EMBA domain files (core frameworks and formulas)
- 31 Quick Reference cards (per-course lookup tables)
- COURSE_CATALOG.md (master router)
- 4 MBA framework guides (assessment, case study, financial modeling, pitch deck)
- 3 communication framework files (protocols, reference cards)
- Individual project capstone reference

Skills add deeper, course-specific instruction sets, but the embedded files provide strong coverage for most use cases.
