# LinkedIn Post: Paroz Work OS

## Draft

I built a personal operating system for AI.

Not an app. Not a SaaS product. A structured knowledge system: 29 files that turn Claude into a work partner who knows my MBA frameworks, my team's tech stack, and my communication style.

Here's the problem: I completed 29 courses in my Cornell-Queen's Executive MBA. Finance, strategy, operations, leadership, marketing, economics, technology, governance. Hundreds of frameworks. But in daily work? Most of them sat in notebooks.

So I built a Work OS: a portable system that loads automatically in every AI session.

How it works:
- 8 knowledge files consolidate all 29 courses into searchable domains
- 5 work context files capture my team, tech stack, stakeholders, and critical SOPs
- 4 templates (decision memo, status update, RCA, user story) produce real deliverables
- 4 workflows (incident response, executive briefing, negotiation, data storytelling) guide high-stakes situations
- A learning loop captures every correction so the system never makes the same mistake twice

The result: when I ask "should we invest in a semantic layer for QuestBank?", the system pulls Porter's Five Forces from strategy, DCF analysis from finance, and frames the recommendation in a 3-page executive memo. Automatically.

Three design principles that make it work:
1. Frameworks first: every response is grounded in a named, referenced framework
2. Portable: the entire system is a folder of markdown files, no dependencies
3. Learning loop: corrections accumulate, so the system gets smarter over time

The compound returns are real. Every correction improves future sessions. Every framework becomes a reusable tool, not a fading memory.

If you're finishing an MBA (or any intensive learning experience), consider this: the knowledge has a half-life. Unless you build a system to operationalize it.

What's your system for applying what you've learned?
