# Data Products — Routing

Registry of live data products (or generic example for forks). Pairs with the DABs Data-Contract Golden Path subproject.

| File | Purpose |
|---|---|
| `data-products.yaml` | Registry: each data product's grain, classification, owner, AI consumption status |
| `ai-consumption-contract-template.md` | Markdown template for the AI Consumption Contract section in PRDs |
| `_example-platinum-domain.md` | Generic example data product entry (forks adapt or replace) |

## How rows in `data-products.yaml` are populated

Each row corresponds to one `data-contract.yml` deployed via the DABs Golden Path subproject. The `governance-audit` skill and `dabs-template-init` skill update this registry.

## The AI Consumption Contract relationship

Every data product with `ai_consumption.enabled: true` in its contract has an AI Consumption Contract markdown auto-generated by `templates/dabs-data-product-template/scripts/generate_ai_contract.py`. The generated contract is the audit-grade record of what AI agents are allowed to consume.
