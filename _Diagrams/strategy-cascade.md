# Roger Martin Strategy Cascade

> Five integrated questions. Strategy is a coherent set of choices, not a list of priorities.

```mermaid
flowchart TB
    Q1[Winning Aspiration<br/>What does winning look like?]
    Q2[Where to Play<br/>Customers · channels · geographies]
    Q3[How to Win<br/>Cost · differentiation · niche]
    Q4[Capabilities<br/>What must we be great at?]
    Q5[Management Systems<br/>How do we sustain it?]

    Q1 --> Q2 --> Q3 --> Q4 --> Q5
    Q5 -. iterate .-> Q1

    classDef cascade fill:#C3B1E1,stroke:#444,color:#000
    class Q1,Q2,Q3,Q4,Q5 cascade
```

**Test of coherence:** any two answers should reinforce each other. If they conflict, the strategy is not yet integrated.
