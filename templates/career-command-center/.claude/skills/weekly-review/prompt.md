# Skill: /weekly-review — Friday Job Search Ritual

## Purpose
A 15-minute end-of-week check-in that keeps the job search moving, honest, and strategic. Run every Friday. The goal is to surface blockers, celebrate small wins, and plan next week's actions — not to generate paperwork.

## Instructions

### Step 1 — Load context
Read `profile.yml` and `job-search/applications-tracker.md`.

### Step 2 — Pipeline review
Present the current pipeline from the applications tracker in this format:

| Company | Role | Stage | Days since last activity | Next action |
|---|---|---|---|---|

Then ask:
1. "Are there any new applications to add?"
2. "Did anything move this week — interviews scheduled, rejections received, offers?"
3. "Any applications that have gone silent for 7+ days? Do you want to follow up or close them?"

Update the tracker accordingly.

### Step 3 — Win of the week
Ask: "What was one small win this week — even if it's just sending one application or having one coffee chat?"

Acknowledge it. Job searching is demoralizing. Wins matter.

### Step 4 — Blocker of the week
Ask: "What felt stuck or hard this week? What slowed you down?"

Diagnose it. If it's a skill gap (e.g., "I don't know how to write a cold message"), flag it and recommend a skill or template. If it's a motivation issue, name it directly.

### Step 5 — Networking check
Based on `profile.yml` networking_comfort score:
- Score 1–2: Ask "Did you make any new connections this week? Even one LinkedIn request counts."
- Score 3–4: Ask "Did you have any real conversations — coffee chats, calls, DMs that got a reply?"
- Score 5: Ask "Did you move any relationships forward toward a referral or introduction?"

### Step 6 — Next week plan (3 specific actions)
Do not write a long to-do list. Write exactly 3 actions for next week:
1. The one application or outreach that will move the needle most
2. One relationship to deepen (follow up, schedule a call, send a thank you)
3. One skill or material to improve (resume section, LinkedIn, STAR story)

Format:
```
Next week's 3 actions:
1. [Specific action — company, person, or task]
2. [Specific action — who you'll contact and how]
3. [Specific skill or material — what you'll improve]
```

### Step 7 — Log the session
Write a brief entry to `_Logs/session-log.md`:
```
## [Date] — Weekly Review
Pipeline: [X] active applications, [X] at interview stage
Win: [one sentence]
Blocker: [one sentence]
Next week: [3 actions, abbreviated]
```

### Closing
"Good work this week. Job searches are marathons, not sprints. See you Monday — or run `/prep-interview` or `/tailor-resume` if something comes up over the weekend."
