# Resume Template

Use this file to store your master resume content. When you run `/tailor-resume`, tailored versions for specific roles are appended below under named sections.

**Format guidance:**
- Max 2 pages for 10+ years experience; 1 page if under 5 years
- Reverse chronological order
- ATS-safe: no tables, no columns, no graphics in the version you upload
- PDF for human readers; .docx for ATS uploads (some systems fail on PDF)
