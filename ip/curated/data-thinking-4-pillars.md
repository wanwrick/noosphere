# Data Thinking — 4 Pillars of Data-Driven Decisions

> **Source:** Yassine Mahboub, Data & BI Consultant. LinkedIn post + [yassinemahboub.com](https://www.yassinemahboub.com/).

## Core insight

The problem isn't that companies lack data — it's that they've stopped *thinking* about it properly. Data Thinking is a mental framework that forces you to slow down, structure, and make data serve a purpose **before** touching a dashboard.

## The 4 Pillars

| # | Pillar | Core question | Key skill | Common failure |
|---|---|---|---|---|
| 1 | **Problem Understanding** | "What decision are we supporting?" | Clarity & scoping | Solving the wrong problem |
| 2 | **Data Framing** | "What data actually matters?" | Focus & filtering | "Everything matters" → nothing matters |
| 3 | **Analysis & Exploration** | "What do the patterns tell us?" | Hypothesis testing | Chasing "smart-sounding" insights |
| 4 | **Communication** | "How do I make others understand?" | Storytelling & alignment | Showing data ≠ creating impact |

## The mindset shift

| ❌ Tool-first thinking | ✅ Data Thinking |
|---|---|
| "We need [Tool X]" | "What decision are we trying to improve?" |
| "Let's build a dashboard" | "What would 'better' look like here?" |
| "We have the data, just visualize it" | "What data actually matters?" |
| "More data = better decisions" | "Right data > more data" |
| Dashboards are the goal | Dashboards are the byproduct |

## When to use this in this practice

- **Pre-build review** — before any new data product enters Design phase, run the 4 questions. If Pillar 1 fails, no point building anything yet.
- **Stakeholder elicitation** — pair with the 10Q Framework. 10Q answers *can we ingest this?*; 4 Pillars answers *should we?*
- **Quarterly initiative review** — a portfolio that has Pillar 4 weakness will produce reports nobody reads.
