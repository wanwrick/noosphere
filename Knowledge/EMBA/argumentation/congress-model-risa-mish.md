# Congress Model — Risa Mish (Cornell)

> Five-claim argument structure used for high-stakes proposals. Each claim is independently verifiable and the audience can walk the chain in either direction.

## The structure

| # | Claim type | What it does |
|---|---|---|
| 1 | **Diagnostic** | Names the gap, problem, or unaddressed need |
| 2 | **Evidence** | Shows what already exists (artifact / capability / proof) |
| 3 | **Consequence** | Quantifies the cost of the gap (delivery failure, cost spike, missed SLA) |
| 4 | **Fit** | Demonstrates alignment with existing operating model (no scope expansion) |
| 5 | **Ask** | Translates the four claims into one decision request |

The fifth claim is the load-bearing one: ask is **formalization**, not expansion. The first four claims earn the right to ask; the fifth defines what is asked for.

## Strategic fiction

Pair the five claims with a Strategic Fiction layer — TODAY (without the change) vs FUTURE STATE (with the change), side-by-side. This makes the argument visceral, not abstract.

## When to use

- Cross-functional proposals where the audience is technical + skeptical.
- Any proposal where the request can be misread as a turf grab.
- Board / steering-committee asks where the chain of reasoning matters more than the bullet list.

## When *not* to use

- Tactical day-to-day decisions (overkill).
- Conversations where trust is already high and a one-liner suffices.

## Tactical rules

- ❌ Don't say "give us [X]." ✅ Say "assign this work a formal owner."
- ❌ Don't position as career growth. ✅ Position as structural gap with operational consequence.
- ✅ Open with the gap (claim 1), not the ask (claim 5).
- ✅ Show the working artifact (claim 2). Theory alone is insufficient with technical audiences.
- ✅ Let the decision-maker draw the line themselves; they need to feel the conclusion is theirs.
