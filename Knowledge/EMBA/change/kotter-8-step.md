# Kotter's 8-Step Change Management

> The canonical change-management sequence. Skipping a step or running them out of order is the most common failure mode.

## The 8 steps

| # | Step | What it does | What "good" looks like |
|---|---|---|---|
| 1 | **Create urgency** | Surface the real, present cost of inaction | Numbers, deadlines, missed SLAs — not generalities |
| 2 | **Form a guiding coalition** | Recruit a small, credible, cross-functional group | 5–8 people with formal authority and informal influence |
| 3 | **Create a vision** | Articulate the destination + the path | One paragraph anyone can repeat |
| 4 | **Communicate the vision** | Saturate the org with the message | Repeated everywhere, in many forms, by many voices |
| 5 | **Empower others to act** | Remove obstacles; delegate authority | Clear decision rights; no permission-asking required |
| 6 | **Generate short-term wins** | Demonstrable progress in <90 days | Visible, measurable, attributable |
| 7 | **Sustain acceleration** | Use early wins to push for more change | Don't declare victory too early |
| 8 | **Anchor in the culture** | Build new behaviors into hiring, evaluation, rituals | Until it becomes "how we do things here" |

## Common failure modes

| Step | Common failure |
|---|---|
| 1 | Manufactured urgency — fakeable, doesn't survive contact with reality |
| 2 | Coalition is one person + their team; lacks cross-functional weight |
| 3 | Vision is "improve X by Y%" — measurable but not motivating |
| 4 | Communicated once, in one channel; assumed received |
| 5 | Empowerment is rhetorical; permission still required |
| 6 | First win is too distant; momentum dies |
| 7 | Premature victory declaration; reverts to old behaviors |
| 8 | Cultural anchoring is HR's job, not leadership's; doesn't stick |

## Applied: platform-team formalization

| Kotter step | Platform-mandate playbook equivalent |
|---|---|
| 1 Urgency | Upcoming migrations + cost-attribution gaps + missed SLAs |
| 2 Coalition | Engineers internally → adjacent-team brief → manager calibration |
| 3 Vision | The Strategic Fiction (TODAY vs FUTURE STATE) |
| 4 Communicate | The 8-slide deck; cross-functional repeatability |
| 5 Empower | Walk in with the working artifact, not a proposal |
| 6 Short-term win | First Q+1 migration on the new pattern |
| 7 Sustain | Cadence: weekly review for 90 days; rotation model opens |
| 8 Anchor | Update the team OS, onboarding docs, leadership cadence |

## When to use

- Any cross-team change that requires sustained behavior shift.
- Org redesigns.
- New platform / methodology / tool rollouts that depend on adoption.
- Post-merger integration.

## When *not* to use

- Tactical operational changes (overkill).
- Decisions that don't require behavior change from anyone.
