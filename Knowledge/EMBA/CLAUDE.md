# Knowledge / EMBA — Routing

Cornell-Queen's EMBA frameworks. These are academic frameworks applied to live work — not "theoretical only."

| Folder | Contents |
|---|---|
| `argumentation/` | Risa Mish Congress Model — five-claim argument structure |
| `negotiation/` | Shai Dubey Negotiation Map + Negotiation Suite (BATNA, ZOPA, Principled, Cornell playbook) |
| `strategy/` | Hambrick Strategy Diamond — five-element strategy |
| `organization/` | Nadler & Tushman Congruence Model — Strategy / People / Work / Structure |
| `change/` | Kotter's 8-Step Change Management |
| `critical-thinking/` | Critical Thinking Suite — IDEALS, know/assume/don't know, 10-10-10, System 1/2 |
| `corporate-finance/` | Corporate Finance Suite — WACC, NPV/IRR, capital structure, EVA, M&A valuation |
| `operations/` | Operations Suite — lean, TOC, queueing, capacity, Six Sigma DMAIC |

## When to use EMBA frameworks vs Knowledge/Frameworks/

| Use EMBA folder when | Use Knowledge/Frameworks/ when |
|---|---|
| The framework has Cornell-specific framing | The framework is generic / domain-evergreen |
| You're mapping live work to academic frames | You're answering a domain question (Finance/Strategy/Ops) |
| Case-interview prep is the goal | Reference for any work output |

The two folders are complementary: EMBA contains specific frameworks the Cornell-Queen's program emphasizes; Frameworks/ is the broader MBA-canon library.
