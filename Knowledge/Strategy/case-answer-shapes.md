# Case Answer Shapes — 4 Prompt Types and Their Frameworks

> Use this file FIRST in any case-prep or strategic-question situation. Identify the prompt type; the matching answer shape and frameworks follow.

## The four prompt types

| Prompt type | Question shape | Framework combo |
|---|---|---|
| **Market Entry / Expansion** | "Should we enter [Market X]?" | PESTLE + Porter's 5F + CAGE + Entry Mode + Sahlman screen |
| **Profitability Decline** | "Why are profits falling?" / "How do we recover them?" | P = R − C decomposition + Porter's 5F + Value Chain + SWOT |
| **Prioritization / Allocation** | "Which initiatives should we fund?" | Strategic Health Matrix + Balanced Scorecard + Critical Few + EVA |
| **Diagnosis / Root Cause** | "What's wrong with [X]?" | Congruence Model + 5 Whys + Issue Tree (MECE) + Pyramid Principle |

## Universal answer shape (every case)

```
Recommendation
   ├── Reason 1 — supported by [evidence A1, A2]
   ├── Reason 2 — supported by [evidence B1, B2]
   └── Reason 3 — supported by [evidence C1, C2]
Risks + mitigations
Next steps
```

This is the Pyramid Principle. Your answer is a **conclusion supported by three reasons supported by evidence**. The Recommendation comes FIRST (BLUF). Three reasons (MECE). Risks + Next steps round out.

## Type 1 — Market Entry / Expansion

**Default frame:**

1. PESTLE → macro attractiveness.
2. Porter's 5F → industry attractiveness.
3. CAGE → distance / fit between current ops and target market.
4. Entry Mode → export / license / JV / wholly-owned (risk-control spectrum).
5. Sahlman screen → people · opportunity · context · risk-reward.

**Watch for:** size-of-prize illusions; assuming the firm has the right capabilities; ignoring exit costs.

## Type 2 — Profitability Decline

**P = R − C.** Decompose:

- **Revenue:** Volume × Price. Volume drops? Price drops? Mix shift?
- **Cost:** Variable + Fixed. COGS shift? SG&A bloat? Capacity utilization drop?

Then apply Porter's 5F (rivalry intensity changed?), Value Chain (where did costs balloon?), SWOT (changes in internal/external context).

**Watch for:** treating "profit" as one thing; ignoring mix shifts; ignoring industry trend.

## Type 3 — Prioritization / Allocation

Score initiatives on:

- **Strategic Health** (does it advance the strategy?)
- **Operational Health** (can the org execute?)
- **Economic Value** (NPV / EVA / payback)
- **Risk** (downside, irreversibility, optionality)

Plot on a 2x2 (high/low Strategic vs high/low Economic). Fund the upper-right quadrant first; stage-gate the upper-left; defer the rest.

**Watch for:** rewarding "easy" projects; not surfacing opportunity cost; treating all dollars as equal.

## Type 4 — Diagnosis / Root Cause

Use the Congruence Model to name the misalignment (Strategy / People / Work / Structure). Then 5 Whys on the symptom. Then issue tree (MECE) the root causes. Synthesize via Pyramid Principle.

**Watch for:** stopping at the first plausible cause; ignoring system-level dynamics; blaming people for a structure problem.
