# Strategy Meta Framework — Choosing the Right Framework

> The framework for choosing frameworks. Used when the strategic question doesn't obviously fit one of the four case-answer shapes.

## The meta sequence

```
Situation Recognition  →  Analysis Path  →  Synthesis  →  Recommendation
       (15%)               (50%)            (25%)         (10%)
```

Spend roughly that share of effort. Most failed strategy work is over-allocated to Analysis and under-allocated to Situation Recognition.

## Step 1 — Situation Recognition

Identify which axis the question lives on:

| Axis | Tells |
|---|---|
| **Existing-market vs new-market** | "Compete better" vs "create market" |
| **Stable vs disrupted** | Slow change vs accelerating change |
| **Internal-vs-external dominant** | Internal capability gaps vs external pressure |
| **Cooperative vs competitive** | Alliances + ecosystems vs zero-sum |
| **Single-decision vs portfolio** | One big bet vs many small experiments |

A question's situation determines the analysis path.

## Step 2 — Analysis Path Selection

| Situation | Default path |
|---|---|
| Existing market, stable, external-dominant | Porter's 5F + Value Chain + SWOT |
| New market, disrupted, internal-dominant | Blue Ocean + Discovery-Driven Planning + DEC |
| Existing market, disrupted, external-dominant | Strategy Diamond + Roger Martin Cascade |
| Cooperative + ecosystems | Platform Economics + Network Effects + Game Theory |
| Portfolio (multi-bet) | Real Options + EVA + Strategic Health Matrix |

Don't be doctrinaire. Most real questions need two or three paths combined.

## Step 3 — Synthesis

Synthesis is **not** "summarize." Synthesis is:

1. Identify the 3–5 highest-leverage findings across the analyses.
2. Identify the 1–2 binding constraints.
3. Identify the trade-offs (this option closes that option).
4. State the *prima facie* recommendation as a hypothesis.
5. Apply pre-mortem: what would make this recommendation wrong?

Synthesis is where strategists earn their pay. Analysts produce findings; strategists turn findings into a posture.

## Step 4 — Recommendation

Pyramid Principle. One recommendation. Three reasons. Each reason supported by evidence from the analysis. Risks + mitigations. Specific next steps with owners + dates.

## When to use this meta-framework

- The question doesn't obviously match a case-answer shape.
- Multiple frameworks seem relevant; need to choose.
- Stakes warrant deliberate framework selection vs reflexive default.
- Teaching others how to think about strategy.

## When *not* to use

- Recurring tactical decisions (use the cached default for that situation).
- When the answer is genuinely obvious (don't manufacture complexity).
